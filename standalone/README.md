# 모아 독립 웹서비스

한국의 만 13~18세 고립·은둔 청소년이 자기 속도에 맞춰 또래 모임에 참여하도록 돕는 웹서비스입니다. Node.js 서버가 회원, 모임, 대화, 신고, 연결 요청을 SQLite 데이터베이스에 저장합니다. 방문자는 ChatGPT 계정 없이 모아의 아이디와 비밀번호로 로그인합니다.

이 디렉터리는 기존 Sites 앱과 분리된 독립 실행 프로젝트입니다. 기존 서비스의 회원이나 대화 데이터는 자동으로 가져오지 않습니다. 외부 호스팅 계정에 배포하기 전에는 공개 서비스 주소가 생기지 않습니다. 배포 절차와 영속 저장소 설정은 [DEPLOYMENT.md](./DEPLOYMENT.md)를 참고하세요.

[Render에서 배포 설정 검토하기](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fja-in0817%2FCOM-s-%2Ftree%2Ffeat%2Findependent-youth-platform)

이 링크는 이 브랜치의 실행 설정을 가져옵니다. 저장소 루트의 `render.yaml`을 사용하며, 서비스 생성은 Render 계정에서 설정과 요금을 확인한 뒤 진행합니다. 현재 구성은 웹서버 한 대와 1GB 영속 디스크를 사용합니다.

## 제공하는 기능

| 기능 | 현재 동작 |
| --- | --- |
| 회원가입 | 운영자가 발급한 일회용 초대코드로 가입합니다. 초대코드에 기록된 연령을 적용하며 참여자가 나이·역할을 임의로 바꿀 수 없습니다. |
| 자체 로그인 | 비밀번호 해시와 서버의 세션을 사용합니다. 비밀번호 변경 시 다른 세션을 종료합니다. |
| 또래 모임 | 만 13~15세와 만 16~18세를 분리하고 3~4명의 참여자 정원을 확인합니다. |
| 모임 추천 | 관심사·일정·참여 방식 등 입력된 조건을 바탕으로 규칙으로 정렬합니다. 실제 가입자가 없는 가짜 모임을 만들지 않습니다. |
| 대화와 일정 | 가입한 모임의 메시지를 읽고 쓰며, 만남 시간을 제안하고 본인의 참여를 기록합니다. |
| 쉬기와 나가기 | 사유 심사 없이 이용할 수 있습니다. 쉬는 동안은 자리를 유지하고 나가면 모임 대화 접근이 종료됩니다. |
| 차단과 신고 | 상호 차단 관계의 새 모임 합류를 막고 메시지를 필터링합니다. 신고는 운영자가 검토합니다. |
| 기관 정보 | 공식 출처가 있는 안내 정보를 제공합니다. 기관과의 제휴나 예약 가능성을 자동으로 보증하지 않습니다. |
| 연결 요청 | 동의한 요청을 모아 서버 내부에 저장합니다. 기관으로 전송하거나 예약을 확정하지 않습니다. |
| 운영자 화면 | 초대코드 발급, 신고 검토, 내부 연결 요청 확인을 지원합니다. |

**구현하지 않은 기능:** AI 진단·자동 제재, 외부 기관 자동 접수, 문자·이메일 발송, 보호자 자동 연락, 영상·음성 통화, 개인 간 DM입니다. `GET /api/me`에도 `ai_enabled: false`, `external_referral: false`를 반환합니다.

초대코드는 연령이나 법정대리인 동의를 독립적으로 확인하는 인증 서비스가 아닙니다. 운영자가 적절한 절차로 확인한 뒤 발급하는 수단입니다. 만 13세의 초대는 연령 확인과 법정대리인 동의 확인이 모두 필요합니다.

## 실행 환경

- Node.js 24와 npm
- SQLite 파일을 쓸 수 있는 디렉터리
- 운영 배포에서는 HTTPS 주소와 영속 디스크

이 구현은 **서버 한 인스턴스와 로컬 영속 디스크**를 사용합니다. 여러 서버에 같은 SQLite 파일을 공유하거나, 임시 파일시스템에 저장하는 구성으로 배포하지 마세요.

회원 신원은 세션 쿠키로 확인하며 클라이언트가 보낸 신원·역할 헤더는 무시합니다. 접속 횟수 제한용 IP는 명시적으로 설정한 신뢰 프록시의 값만 사용합니다. Render와 다른 호스트의 신뢰 조건은 [배포 안내](./DEPLOYMENT.md)의 환경 변수 절을 참고하세요.

## 로컬에서 실행하기

아래 명령은 `standalone` 디렉터리에서 실행합니다.

```bash
npm ci
cp .env.example .env
npm run build
```

기본 `.env` 설정은 다음과 같습니다.

```dotenv
PORT=3000
APP_ORIGIN=http://localhost:3000
DATABASE_PATH=./data/moa.sqlite
NODE_ENV=development
```

최초 운영자 계정을 만든 뒤 서버를 실행합니다. Bash 또는 Git Bash에서 비밀번호를 화면과 명령 기록에 남기지 않고 표준입력으로 전달할 수 있습니다.

```bash
read -r -s -p '운영자 비밀번호: ' MOA_ADMIN_PASSWORD
printf '\n'
printf '%s' "$MOA_ADMIN_PASSWORD" | npm run admin -- create-admin operator
unset MOA_ADMIN_PASSWORD
npm start
```

아이디는 영문·숫자·밑줄 3~32자, 비밀번호는 12~128자입니다. `operator`는 예시 아이디이며 기본 비밀번호는 제공하지 않습니다. 서버가 시작되면 <http://localhost:3000>을 열고 운영자로 로그인하세요. 운영자 화면에서 실제 참여자 확인 후 초대를 발급하면 그 코드로 참여자가 가입할 수 있습니다.

브라우저 주소와 `APP_ORIGIN`은 일치해야 합니다. 예를 들어 `localhost`로 설정한 뒤 브라우저에서 `127.0.0.1`로 접속하면 변경 요청이 거절될 수 있습니다.

## 화면을 수정하며 개발하기

개발 화면은 Vite의 5173번 포트에서 열리므로 API 서버의 허용 주소도 그 주소로 맞춥니다.

첫 번째 터미널:

```bash
APP_ORIGIN=http://localhost:5173 npm start
```

두 번째 터미널:

```bash
npm run dev -- --port 5173 --strictPort
```

브라우저는 <http://localhost:5173>을 사용합니다. Vite가 `/api` 요청을 로컬 API 서버로 전달합니다. 운영 배포에서는 Vite 개발 서버를 사용하지 않고 `npm run build`로 만든 화면을 Node 서버가 제공합니다.

## 검증하기

```bash
npm test
npm run typecheck
npm run build
```

통합 테스트는 실제 HTTP 서버를 임시 포트에 띄우고 쿠키·CSRF 토큰으로 요청합니다. 테스트마다 별도 임시 데이터베이스를 만들며 운영 데이터를 사용하지 않습니다. 다음 동작을 검증합니다.

- 로그인·세션·비밀번호 변경과 권한 헤더 위조 거부, 요청 본문 수신 중 로그아웃한 세션의 변경 차단
- Origin·JSON·CSRF 검증과 초대코드의 연령·동의·일회성 조건
- 연령별 모임 분리, 동시 합류 시 정원, 휴식과 즉시 탈퇴
- 비회원의 대화 접근 거부, 메시지 중복 방지, 차단
- 운영자만 가능한 신고 검토·메시지 숨김·참여 제한과 재검토 후 복구
- 연결 요청의 동의·개인별 조회·취소·내부 대기 상태
- 계정 탈퇴 후 로그인 차단과 대화·연락처·관련 신고 상세 내용 삭제
- 서버 재시작 후 회원·모임·대화·연결 요청 유지
- SQLite 본체·WAL·SHM 파일의 소유자 전용 권한과 신뢰 프록시의 접속 IP 검증

테스트는 서비스의 치료 효과, 실제 연령 확인, 외부 기관의 처리 결과를 검증하지 않습니다.

## 파일 구성

```text
server/         HTTP 서버, 인증, 데이터베이스, 도메인 API
web/            React 화면
test/           실제 HTTP 통합 테스트
dist/           화면 빌드 결과
data/           로컬 SQLite 저장소
API_CONTRACT.md API의 입력과 응답 계약
DEPLOYMENT.md   서버 배포와 백업 안내
```

데이터베이스, 백업, `.env`, 실제 초대코드나 비밀번호를 Git에 커밋하지 마세요. 시·군·구와 개인 참여 설정은 다른 참여자에게 공개하는 모임 구성원 정보에 포함되지 않습니다. 운영자는 신고와 연결 요청을 처리할 담당자와 연락 방식을 별도로 준비해야 합니다.
