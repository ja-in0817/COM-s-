# wargether

전쟁과 이주로 일상이 끊긴 사람들이 학습과 여가를 함께하며 관계를 이어가는 웹 프로토타입입니다.

## 실행

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다.

```bash
npm start
```

`http://127.0.0.1:3000`을 브라우저에서 엽니다. `PORT`로 포트를 바꿀 수 있습니다.

```bash
npm test
npm run build
```

- `npm start`: 프런트엔드와 상태 저장 API를 함께 제공하는 단일 사용자 로컬 개발 모드입니다. 데이터는 `backend/data/state.json`에 저장됩니다.
- `npm run build`: `build/`에 정적 사이트를 만듭니다. 정적 호스팅에서는 브라우저 localStorage만 사용합니다.
- 기존 Sites 배포는 정적 체험 버전입니다. 이 저장소의 로컬 백엔드가 Sites에서 실행되는 것은 아닙니다.

## 코드 구조

| 디렉터리 | 역할 |
| --- | --- |
| `frontend/public/` | HTML, CSS, 화면 렌더링, 입력 처리, 저장 상태 표시 |
| `backend/src/` | Node.js HTTP 서버, 상태 API, 파일 저장 |
| `shared/` | 안부 요청 및 과반수 신고 계산 규칙 |
| `tests/` | 도메인 규칙과 이전 브라우저 데이터 호환성 테스트 |
| `backend/test/` | API 접근, 충돌 감지, 재시작 후 보존 테스트 |
| `scripts/` | 정적 사이트 빌드 |
| `docs/` | 기존 체험 화면 참고 이미지 |

## 기능과 구현 범위

멘토/멘티 선택, 학습과 여가를 함께 포함하는 모임, 참여·저장·주제 제안·투표, 공지와 출석 관리, Zoom·카카오 오픈채팅·Discord 링크를 지원합니다.

사전 공지 없는 불참이 3회 이상인 참여자에게 같은 모임의 동료가 안부 요청을 남길 수 있습니다. 서로 다른 3명의 요청이 모이면 기관 전달 대기 항목이 한 번 생성됩니다. 실제 구호기관 연락처, 발송 채널, 접수 확인은 연결되어 있지 않습니다. `sentAt`을 임의로 기록하거나 전송 성공으로 표시하지 않습니다.

규칙 위반 신고는 안부 요청과 분리합니다. 현재 참여자 중 대상자를 제외하고 모임장을 포함한 인원 N에 대해 `floor(N/2)+1`명의 신고가 있어야 모임장이 검토 후 해당 모임에서 퇴출할 수 있습니다. 중복 신고는 한 명으로 계산하고, 퇴출·복원 이력을 남깁니다. Zoom 등 외부 서비스 계정에는 영향을 주지 않습니다.

## 운영 전 필요한 작업

현재는 단일 사용자가 여러 역할을 체험하는 프로토타입입니다. `me`는 인증된 사용자 ID가 아니며, 로컬 개발 쿠키도 실제 계정 인증이 아닙니다. 상태 API는 화면 상태 전체를 저장하므로, 조작된 클라이언트에 대해 역할·투표의 진위를 보장하지 않습니다. 실제 서비스로 운영하려면 서버 인증·권한 검증, 사용자별 데이터베이스, 기관 계약 및 발송 워커, 동의·보관 정책, 장애 대응이 필요합니다. 개발 서버는 loopback 주소에만 바인딩합니다.

기존 체험 기록을 보존하기 위해 localStorage 키 `moa-v1`과 내부 `MoaSafety` 식별자는 유지했습니다. 사용자에게 보이는 서비스 이름은 wargether입니다.
